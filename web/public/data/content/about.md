cellauto is a research-style library and static data backend. Python computes everything that can be precomputed (catalogs, trained weights, analyses, golden fixtures) and exports it as schema-validated JSON; the browser runs the simulations itself. Credits: Lenia by Bert Chan (Chakazul/Lenia, MIT), Growing Neural Cellular Automata by Mordvintsev et al.
